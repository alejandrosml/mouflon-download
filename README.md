# Mouflon

*English first, [français plus bas](#français).*

## English

Mouflon brings little companions to your desktop, on the **Mac**, on
**Windows**, and on **Linux** as a preview. Sheep of real breeds drop from the
top of the screen, stroll along your windows, graze, meet, play, doze off, and
let you catch them and throw them across the desktop.

**Presentation: https://alejandrosml.github.io/Mouflon/**

This repository only holds the files of the latest version, under
[Releases](https://github.com/alejandrosml/mouflon-download/releases):

| File | What it is |
|---|---|
| `Mouflon-macos-arm64.zip` | the Mac app (Apple Silicon), signed with a Developer ID and notarized by Apple |
| `Mouflon-windows-x64.zip` | the Windows folder (64-bit): nothing to install, double-click `Mouflon.exe` |
| `Mouflon-linux-x86_64.tar.gz` | the Linux preview (x86_64, X11) |
| `Mouflon-source.zip` | the source code of that version |
| `SHA256SUMS` | the checksums of the four files above |
| `Mouflon-version.txt`, `Mouflon-version.txt.sig` | the list of those four files (version, sizes, SHA-512 sums) and its signature by the author: an installed Mouflon reads it to update itself, and installs nothing the list does not announce. The author's public key is [`cle-de-signature.pub`](cle-de-signature.pub) |

Mouflon is open source, under the [MIT License](LICENSE-MIT) or the
[Apache License 2.0](LICENSE-APACHE), at your option. Each version comes with
the archive of its source code, `Mouflon-source.zip`, which is enough to
rebuild Mouflon: the Linux package is built from that very archive. (The
“Source code” links GitHub adds to a release by itself only hold this page.)

Questions: asml@laposte.net.

Mouflon is made by Alejandro San Martin Lamas
([github.com/alejandrosml](https://github.com/alejandrosml)).

du haut de l'écran, se promènent sur tes fenêtres, broutent, se rencontrent,
jouent, s'endorment, et se laissent attraper et lancer à travers le bureau.
